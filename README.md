# Ryann Penrod — Portfolio

Personal portfolio showcasing my UX, HCI, and front-end work, including research projects from BYU's Family History Technology Lab.

## Projects

- **Relative Finder** — a web app that helps users find and connect with their relatives ([relativefinder.org](https://relativefinder.org/))
- **Project G.I.F.T.** — a FamilySearch collaboration helping people find and share ancestors ([gift.fhtl.org](https://gift.fhtl.org))
- **ScripShare** — an in-progress app for quick, easy scripture study

## Built with

- Semantic HTML
- CSS (custom properties, Grid, Flexbox, scroll-snap, responsive media queries)
- Vanilla JavaScript for the image carousels

Accessibility features include a skip link, labeled icon links, visible focus states, descriptive alt text, and reduced-motion support.

## Run locally

```bash
python3 -m http.server 8000
```

Then visit [http://localhost:8000](http://localhost:8000).
